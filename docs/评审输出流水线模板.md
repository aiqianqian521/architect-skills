
# 架构师统一评审·输出流水线模板（Pipeline Template）

> 目标：把「蜂群评审 → 统一成品报告 → 质量门禁」固化成一个**可复用模板**。以后对任意项目评审，只需：① 在配置加一行 ② 跑一条命令。输出与精度信号自动给出。

## 一、模板组成

| 文件 | 作用 |
|------|------|
| `pipeline.config.json` | **项目注册表**。加新项目 = 加一行。 |
| `scripts/swarm-to-template.cjs` | 适配器：蜂群 agents[] → 声明式模板输入契约；自动推导架构图；保留原始 type。 |
| `scripts/eval-to-report.cjs` | 单项目一键：适配+渲染+强校验+落盘。 |
| `scripts/run-pipeline.cjs` | **批量**：读配置对全部/单项目执行+汇总质量信号表。 |
| `ai-skill-output-template/templates/*.json` | 声明式输出模板（architect.single-report 等）。 |

## 二、怎么用（三步）

### 1) 注册项目 —— `pipeline.config.json` 加一行
```json
{
  "name": "my-project",
  "fixture": "tests/fixtures/eval-my-project.json",
  "out": "E:/path/to/my-project/docs/architecture-report.md",
  "template": "architect.single-report",   // 可选，缺省用 defaultTemplate
  "family": "architect"                    // 可选
}
```

### 2) 让蜂群 skill 产出原始评审 JSON
形态：`{ "project": "...", "evaluatedAt": "...", "agents": [ { "agent","dimension","status","findings"[], "coverage", "meta" } ] }`
放到 `tests/fixtures/`（或配置里指定绝对路径）。

### 3) 跑流水线
```bash
# 批量全部项目
node scripts/run-pipeline.cjs
# 只跑单个项目
node scripts/run-pipeline.cjs --once my-project
# 单项目单条命令（含项目名覆盖）
node scripts/eval-to-report.cjs tests/fixtures/eval-my-project.json --project my-project --out E:/.../report.md
```

输出：
- 每个项目的统一成品 `report.md`（frontmatter + 五段）；
- 汇总表：findings / critical / high / coverage / errs / warns；
- 质量信号（WARN）：**other 桶饱和、缺 scheme 分级引用、证据缺 file:line**。

## 三、质量门禁到底卡什么（模板的约束力）

`validate.mjs` 按 `architect.single-report` 模板声明强校验：
- frontmatter 必填齐全；
- narrative 四件套（结论/关键发现/加固建议/下一步）有实质内容；
- **证据须行级来源**（`path:line` / `path L123` / `file.47KB`）——否则 WARN；
- **分级须引用 scheme 触发条件**（`scheme 一.1` / `§` / `一.1`）——否则 WARN；
- **other 桶饱和度 ≤ 50%**——超标 WARN（精度信号！）；
- 禁词检测。

> 这些 WARN 非阻断，但每条都直接指向评审质量可改进点。修复蜂群 agent 标注后重跑即可清零。

## 五、自定义：换/加输出模板
- 已有：architect.single-report / cspm.report / ooda.loop / ooda.incident / obsidian.note。
- 需新形态：复制 `ai-skill-output-template/templates/<某>.json`，改 sections/frontmatter/validation，见 `templates/README.md`。
- 在配置的 `template` 字段指向新模板 id 即可，脚本零改动。
